Add a device

  1. Enter a Node ID (any name) and a relative speed below — higher numbers simulate faster hardware.
  2. Choose whether it joins as active (rebalances in immediately) or standby (held in reserve for recovery).
  3. Click Add device — a real daemon process spawns on this machine, running the same model.
  4. Watch the Activity tab or the ticker above for device joined → rebalanced.

  3. Make sure a firewall (or VPN splitting you onto different subnets) isn't blocking the port.

Upload your own

Select config.json, tokenizer files (vocab.json, merges.txt, tokenizer_config.json), and the weights file (pytorch_model.bin or model.safetensors) — ctrl/cmd-click to select several at once. Only usable by devices simulated on this machine — a friend's real laptop needs the same files locally and its own --model pointing at them.
